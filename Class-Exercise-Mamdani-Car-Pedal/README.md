# Class exercise: one fuzzy rule, five implications

The rule "IF the car's speed is slow AND its acceleration is small, THEN the force on the pedal is large", evaluated with five implication operators: Mamdani product, Mamdani min, Dienes-Rescher, Lukasiewicz and Zadeh. The scripts plot the AND (product t-norm) of the two premises over speed and acceleration, and the resulting relation for each implication.

- `Q1.m`: sigmoid-shaped membership functions
- `Q2.m`: piecewise-linear membership functions
- `figures/`: plots from running both scripts
